## 1. النطاق والموافقة

تسري هذه الاتفاقية طوال دورة حياة المشروع، بما في ذلك البحث والتصميم والتطوير
والعروض والاختبارات الداخلية والميدانية والنشر والتشغيل والتقييم والصيانة
والتكرار وإنهاء الخدمة. وتشمل تطبيق الويب وقنوات المراسلة ومساحات المشاريع
والمواد المرفوعة والمخرجات والأدوات وواجهات الاسترجاع وأي واجهة مستقبلية تشير
إلى هذا الإصدار.

بإنشاء حساب أو قبول هذه الاتفاقية أو الاستمرار في الاستخدام بعد تغيير جوهري،
فإنك توافق على هذه الاتفاقية وتقرّ بسياسة الخصوصية. إذا لم توافق، فلا تستخدم
الخدمة. قد يخضع نشر معيّن أيضاً لشروط بحثية أو وظيفية أو تعاقدية أو ميدانية
معتمدة، وتُطبّق الشروط التي تمنح حماية أقوى للمستخدم.

## 2. الأهلية والحسابات

يجب أن يكون عمرك 18 سنة على الأقل، أو أن تستخدم الخدمة تحت إشراف بالغ أو جهة
مؤسسية وفق إجراء معتمد. استخدم حساباً يحق لك استخدامه وقدّم معلومات هوية صحيحة
عبر مزوّد تسجيل الدخول. أنت مسؤول عن نشاط جلستك وعن تسجيل الخروج من الأجهزة
المشتركة. لا يطلب التطبيق كلمة مرور Google ولا يحفظها.

لا يعني التسجيل المفتوح أنك أصبحت عضواً أو موظفاً أو مستفيداً لدى RAISE أو ESDU
أو AUB أو أي مانح أو شريك. تُمنح صلاحيات الإدارة بشكل منفصل ولا تعتمد على نطاق
البريد الإلكتروني وحده.

## 3. هدف الخدمة

تقدّم الخدمة دعماً مبسّطاً للقرارات الزراعية والعلمية والبيئية والاقتصادية
ومشاريع الريف. يمكنها استرجاع المعرفة المحلية المراجعة والبحث في مصادر معتمدة
وإجراء حسابات محدودة وطلب توضيحات وإنشاء خطط وميزانيات وتقاويم وقوائم تحقق أو
مذكرات إحالة. هدفها مساعدة المستخدم على فهم الخيارات والاستعداد لقرار أفضل،
ولا تتخذ القرار نيابة عنه.

## 4. حدود الذكاء الاصطناعي ومسؤولية المستخدم

قد يكون المحتوى المولّد آلياً ناقصاً أو قديماً أو غير مناسب للحالة أو خاطئاً،
حتى لو بدا واثقاً أو أرفق مصادر. توضح الاستشهادات الأساس المستخدم، لكنها لا
تضمن صحة الجواب لمزرعة أو حيوان أو مشروع أو بلدة أو موسم أو شخص محدد.

يجب التحقق بصورة مستقلة من المخرجات المهمة. لا تحل الخدمة محل مهندس زراعي أو
طبيب بيطري أو طبيب أو مختبر أو مهندس أو محاسب أو محام أو مستشار مالي أو جهة
مختصة بالمبيدات أو سلامة الغذاء أو خدمة طوارئ. لا تؤخر إجراءً طارئاً بانتظار
جواب من الخدمة.

لا تعتمد على الخدمة وحدها لاختيار المبيد أو الجرعة، أو الوصفات البيطرية، أو
التشخيص، أو سلامة الغذاء والمياه، أو الأعمال الإنشائية والكهربائية، أو الالتزام
القانوني، أو الائتمان والتأمين، أو القرارات المالية الكبيرة. الأسعار والأنظمة
والتسجيلات والطقس والإنذارات المرضية والأسواق متغيرة وتحتاج إلى تحقق محلي حديث.
لا يضمن أي مخرج الإنتاج أو الربح أو الأهلية أو الموافقة أو السلامة أو الامتثال.

## 5. الأدوات والملفات المولّدة

قد تستخدم الخدمة أدوات مقيّدة للبحث في المعرفة المعتمدة أو تحويل الوحدات أو
حساب السيناريوهات أو إنشاء ملفات قابلة للتنزيل. تبقى النتائج مرتبطة بجودة
المدخلات والافتراضات والوحدات والتواريخ وحدود المصادر. راجع الصيغ والمجاميع
والتواريخ واللغة والتعليمات العملية قبل الاستخدام.

لا توفر الخدمة وصولاً إلى نظام التشغيل أو تنفيذاً عشوائياً للبرامج، ولا تملك
صلاحية تقديم الطلبات أو شراء السلع أو الاتصال بالغير أو إلزام أي مؤسسة، إلا إذا
نصّت ميزة معتمدة منفصلة على ذلك بوضوح.

## 6. المحتوى الذي تقدمه

تحتفظ بالحقوق التي تملكها في الأسئلة والتعليمات والملفات والصور والتقييمات
والمواد التي تقدمها. وتمنح الجهة المشغلة والمعالجين المعتمدين إذناً محدوداً
لاستضافة هذا المحتوى ونسخه وتحويله واسترجاعه ونقله بالقدر اللازم لتشغيل الخدمة
وحمايتها ودعمها وتقييمها وتحسينها وفق سياسة الخصوصية.

لا ترفع إلا مواد يحق لك استخدامها. لا ترفع سجلات مؤسسية سرية أو قوائم مشاركين
أو أرقام هوية أو بيانات دخول أو سجلات دفع أو صحة أو مواقع منازل دقيقة أو أرقام
هاتف خاصة أو بيانات شخصية للغير أو معلومات حساسة. تقبل عمليات النشر الحالية
مواد زراعية عامة أو غير حساسة فقط، ما لم يجز بروتوكول وموافقة منفصلان فئات أخرى.

الملفات المرفوعة سياق يقدمه المستخدم وليست معرفة رسمية معتمدة للمشروع، ولا
يمكنها تجاوز تعليمات النظام أو ضوابط السلامة. يمكن استخدام الملاحظات لإصلاح
الأخطاء وتقييم الخدمة. يتطلب الاقتباس المنسوب لشخص أو الاستخدام البحثي أو النشر
العام موافقة منفصلة وأي اعتماد أخلاقي مطلوب.

## 7. الاستخدام المقبول

يُحظر عليك:

- تجاوز ضوابط الوصول أو الحصص أو وسائل الحماية أو قيود الأدوات؛
- محاولة الوصول إلى معلومات مستخدم آخر أو انتحال شخصية الغير؛
- رفع برمجيات ضارة أو ملفات تنفيذية أو مواد لا تملك حق استخدامها؛
- استخدام الخدمة للإضرار أو الخداع أو التمييز أو استغلال الناس أو الحيوانات أو
  الممتلكات أو الأسواق أو البيئة؛
- إنتاج رسائل مزعجة أو مراقبة غير قانونية أو ادعاءات احتيالية أو إرشاد محظور؛
- تقديم مخرج غير متحقق منه على أنه قرار رسمي صادر عن RAISE أو ESDU أو AUB أو
  جهة حكومية أو مهنية؛ أو
- تعطيل الخدمة أو الاختبارات أو الاستجابة للحوادث أو سجلات التدقيق.

يتطلب اختبار الأمان موافقة خطية مسبقة ونطاقاً متفقاً عليه. أبلغ عن أي مشكلة أمن
أو خصوصية إلى {{PRIVACY_CONTACT}}، ولا تنشر تفاصيلها ما دام المستخدمون معرضين
للخطر.

## 8. الخدمات الخارجية

تعتمد الخدمة على مزودين للهوية والاستضافة وقواعد البيانات والتخزين والذكاء
الاصطناعي والبحث والصوت والمراسلة. قد يؤثر توفرهم وشروطهم في الخدمة. تحدد سياسة
الخصوصية الفئات الحالية ومتى يمكن نقل المحتوى. الروابط الخارجية مقدمة للاستدلال
والتسهيل، ولا يتحكم المشروع في محتواها.

## 9. التوفر والتغيير وإنهاء الاستخدام

قد تتغير الميزات والنماذج والمصادر والأدوات والحصص والقنوات خلال دورة حياة
المشروع. يمكن تعليق ميزة أو حساب لمعالجة مخاطر الأمن أو الخصوصية أو السلامة أو
سوء الاستخدام أو المتطلبات القانونية أو التمويل أو التشغيل. قد تتوقف الخدمة أو
تتأخر أو تنتهي، وهي ليست خدمة طوارئ أو خدمة مضمونة الاستمرار.

يمكنك التوقف في أي وقت. تتيح الضوابط المتوفرة تصدير بيانات مساحة العمل وحذف
المحتوى والحساب. قد تنتهي النسخ الاحتياطية وسجلات الأمان لدى المزودين وفق جداول
منفصلة موضحة في سياسة الخصوصية. لا يلزم حذف المؤشرات المجمعة المجهلة فعلياً التي
لم يعد من المعقول ربطها بك.

## 10. هوية المشروع والملكية الفكرية

ترخيص البرنامج وحقوق مصادر المعرفة وأسماء المشروع والعلامات المؤسسية ومحتوى
المستخدم أمور منفصلة. لا يمنحك الوصول إذناً باستخدام أسماء أو شعارات أو منشورات
RAISE أو ESDU أو AUB أو المانحين أو الشركاء. لا يجوز وصف مادة مولدة بأنها معتمدة
مؤسسياً ما لم يوافق عليها صاحب صلاحية.

## 11. المسؤولية والنزاعات

تُقدّم الخدمة لدعم القرار والتقييم ضمن الضوابط والحدود المبينة. لا تستبعد هذه
الاتفاقية أي حق أو مسؤولية لا يجوز قانوناً استبعادها. يجب توثيق المؤسسة المسؤولة
والقانون المطبق ومسار الشكوى وتسوية النزاعات في سجل اعتماد النشر قبل الاستخدام
العام في الإنتاج. إلى حين ذلك، يبقى الاستخدام ضمن عملية تقييم مصرح بها.
