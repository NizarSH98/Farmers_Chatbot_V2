# Documentation archive

Purpose: preserve superseded plans and dated reviews without mixing them with
current build and operating instructions.

Files here are historical evidence only. They may mention removed providers,
old assumptions, or incomplete milestones. Do not use them to start, configure,
deploy, or assess the current application.

Provider-specific deployment files and dead runtime code were removed rather
than copied here because Git history already preserves them and keeping
executable-looking legacy files would create operational risk.
